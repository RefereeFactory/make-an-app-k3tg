How it works

  1. Write it down. Give your note a title and jot the text. Pick a colour so it stands out later.
  2. Save it. Press Save note and it's stored permanently in the cloud — no account needed.
  3. Find it again. Your notes load automatically each visit, newest first. Use the search box to sift through them.
  4. Edit or remove. Tap Edit on any note to change it, or Delete when you're done with it.
